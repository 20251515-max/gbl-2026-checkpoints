# 게임기반학습 체크포인트 저장소

2026학년도 2학기 게임기반학습 실습의 단계별 완성본을 모아 두는 저장소입니다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| stage-0 | 출발 파일 — AGENTS.md, codex.md |
| stage-1 | 1단계 완성본 — 기본 전투 화면 |
| stage-2 | 2단계 완성본 — 화면 배치 조정 |
| stage-3 | 3단계 완성본 — 상단 UI 개선 |
| stage-4 | 4단계 완성본 — 전투 연출 추가 |
| stage-5 | 5단계 완성본 — 몬스터 두 종 추가와 스테이지 JSON |

stage-1부터는 수업이 진행되면서 하나씩 올라옵니다.

## 사용 방법

1. **처음 한 번** — VS Code에서 `Ctrl + Shift + P` → `Git: Clone` → 이 저장소 주소를 붙여 넣어 내려받습니다.
2. **출발** — `stage-0`의 파일을 내 프로젝트 폴더(`castle-defense`)로 복사합니다.
3. **뒤처졌을 때** — 이 폴더를 열고 소스 제어의 `…` 메뉴에서 **Pull**을 선택해 새 단계를 받습니다. 필요한 `stage-N` 폴더의 파일을 모두 내 프로젝트 폴더로 복사해 덮어쓴 뒤, 내 프로젝트에서 `체크포인트 N단계에서 이어감`으로 커밋합니다.

## 주의

- 이 폴더에서는 Codex를 실행하거나 파일을 고치지 않습니다. **받아 오기만 하는 곳**입니다.
- 실제 작업은 언제나 내 프로젝트 폴더에서 합니다.
